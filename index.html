Capabilities

When AI needs guardrails, not just prompts

01

AI + Hard Logic in One Graph

LLM nodes for intelligence. If/else, map, and router nodes for deterministic control. Human checkpoints for judgment calls. Every decision is auditable, every branch is explicit, every error is handled by policy — not by crashing.

Core
02

Smart Error Handling

Every node has an error policy: 409 Conflict → skip. Timeout → retry. File missing → continue. Users override per-node in the config panel. No more workflows crashing on expected conditions.

03

Dynamic Config Panels

Node config UIs are 100% schema-driven. Grouped fields, conditional visibility, folder pickers, action buttons — all from Python annotations. Zero custom frontend code per node.

04

Step-by-Step Wizard

Click “Wizard” on any node. Walk through each field one at a time with full descriptions.

05

Version Control

Every save records who edited, when, and which DrawLabs version. Full edit history. Original creator preserved.

06

Compatibility Check

Import a workflow? DrawLabs checks if all node types exist locally. Missing nodes → clear warning before import.

AI Assistant

Meet Sage

Three ways to work with AI inside DrawLabs:

  • 🛠 Build with Sage — describe what you need, Sage generates a complete workflow. Live canvas preview updates as you chat.
  • 💬 Ask Sage — quick questions, debugging, “what does this node do?” Voice-enabled with auto-detect silence.
  • 💻 Build a Node — describe a custom node type, Sage writes Python code, you review and edit in a dark-theme IDE, NDK validator gates quality, one-click hot-install.

Sage is persona-aware — it uses your industry’s language. A healthcare user hears “Pull Patient Record” not “fhir_pull.”

Installation
  1. Download and open the .dmg file
  2. Drag DrawLabs to Applications
  3. Before first launch, open Terminal and run: xattr -cr /Applications/DrawLabs.app Removes the quarantine flag (app is unsigned during alpha).
