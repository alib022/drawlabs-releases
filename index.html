The concept

Two worlds, one canvas

Healthcare AI has a fundamental tension: you need AI to be smart and autonomous, but regulations demand every step be auditable, deterministic, and compliant. DrawLabs solves this by letting you wire both together visually.

Capabilities

Built for the hardest healthcare data problems

01

DICOM De-Identification

Three-layer pixel redaction: margin blackout + EasyOCR deep learning text detection + LLM PHI classification. Tag stripping with allowlist approach. Safe Harbor compliant with built-in LLM verification.

02

FHIR R4 De-Identification

Pull patient data via $everything, de-identify all resources with consistent cross-modal ID hashing. Same hash salt as DICOM for unified patient pseudonyms.

03

Autonomous AI Agents

MCP-powered agents that reason in loops, pick tools, and solve complex tasks. Grant them access to specific servers — they figure out the rest.

04

Resumable at Scale

Processing millions of files? UID-based DICOM trackers pick up exactly where you left off. No re-processing, no duplicate work.

05

Google Healthcare API

Native support for DICOMweb and FHIR on Google Cloud Healthcare. Service account auth — no gcloud CLI, no library dependencies.

06

Human-in-the-Loop

Pause any pipeline for human review. Built-in DICOM viewer with image rendering and full tag tables. Approve, reject, or annotate before proceeding.

07

Schedule & Watch

Cron schedules, interval timers, and folder watchers. Enable always-on mode and pipelines run automatically in the background via macOS launchd.

08

Local-First & Secure

Everything on your machine. Secrets in the OS keychain. Encrypted at rest. No cloud dependency. Data never leaves unless you explicitly push it.

09

Headless & Background Runs

Run workflows in the background without a UI window. The app hides to the system tray while jobs continue. Attach a live monitoring window at any time to observe progress, console output, CPU/memory usage, and network activity — without disrupting the run. macOS notifications on completion or failure.

10

Voice AI

Built-in speech-to-text (Whisper) and text-to-speech (OpenAI TTS) nodes. Speak to the help assistant to build workflows by voice. Voice Input nodes pause pipelines for live mic recording. Auto-play audio responses through system speakers.

Medical Imaging

DICOM Block DE-ID Pipeline

Pull a list of patients from your PACS, then process each patient in parallel using a Block node — a nested sub-workflow that runs concurrently. Each block pulls the patient's studies, strips PHI from tags, verifies Safe Harbor compliance via LLM, redacts burned-in text with OCR, and uploads clean files to a destination server. Failed files are routed to a review queue.

  • Parallel patient processing (configurable concurrency)
  • Resumable via DICOM UID-based tracker
  • LLM Safe Harbor verification gate
  • Three-layer pixel redaction (margin + OCR + LLM filter)
  • Full audit database of every processed instance
